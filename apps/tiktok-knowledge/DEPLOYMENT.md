# 一键安装与维护

在 Harvey 主菜单进入 **11 应用系统 → 123 TikTok 知识系统**。应用菜单提供安装、更新、卸载、超级管理员账号、域名、状态和日志操作。

首次安装会拉取发布镜像、提示设置超级管理员用户名和密码，随后启动网站、PostgreSQL 和内部数据接口。安装完成显示网站地址和 `/admin/login` 后台登录地址。使用刚设置的账号登录，在管理后台导入私有知识包，再新增或批量导入员工。安装目录为 `/opt/tiktok-knowledge`，默认端口为 `8791`。

如果 GHCR 拉取失败，安装器会按服务器架构下载 GitHub Release 中的 amd64 或 arm64 镜像包，校验 SHA256 后导入 Docker。

## 域名访问

将域名解析到服务器后，在应用菜单选择 **5 添加域名访问**。脚本复用现有 Nginx 和证书功能，并同步网站的访问地址配置。已用于其他网站的域名会被拒绝覆盖。选择 **6 删除域名访问** 时只操作与此应用关联的反向代理配置。

## 更新与数据

选择 **2 更新** 会使用对应版本的发布镜像。更新前自动保存数据库及配置到 `backups/latest-pre-update`，成功后保留这一份更新前恢复包。新应用健康检查失败会尝试恢复旧应用镜像和旧配置。

从 0.1.0 升级时，数据库会增量增加用户名和密码字段。首次启用账号密码登录会提示创建一个新的超级管理员。人员、原始和自定义令牌、权限、考核及知识内容继续从原数据库读取，域名和端口使用原安装配置。已有密码管理员时，正常更新直接使用现有账号。

应用的数据目录分别为 `data` 和 `postgres`。更新保留这些目录，菜单 **3 卸载** 也会保留全部数据和配置，随后重新安装可以继续使用。

更新前恢复包包含数据库和配置。完整迁移到另一台服务器还需要复制 `data` 中的图片、视频及知识资源。备份文件和 `.env` 含私有数据，应存放在自己的安全位置。

应用初始化后，人员权限、账号密码和知识内容均以数据库为准。员工可以继续在网站首页使用访问令牌登录。

迁入原系统时，在知识库管理中导入私有知识包，其中包含章节、题库、正文图片和带货闭环。在成员管理中导入人员包，保留原访问令牌。通过知识管理页的数据统计及前台正文、题库和闭环逐项核对导入结果。

超级管理员可访问全部模块。已授权但缺少章节的模块显示待导入状态，并提供知识管理入口。知识管理页支持编辑保存带货闭环。

员工修改自定义令牌后，认证、后台和导出数据在同一事务内同步。成员管理页每30秒自动刷新，返回页面时也会同步，并提供“刷新成员数据”按钮和同步时间。正在编辑表单时自动刷新会等待，以便完成当前输入。

## 超级管理员账号

应用菜单 **4 设置/重置超级管理员账号** 会列出超级管理员，可选择一个账号重设用户名与密码，也可选择 **0 新增超级管理员**。用户名支持3到64个字母、数字、下划线、点或短横线，统一使用小写，密码支持8到128个字符。

重置操作针对明确选中的超级管理员，并撤销该账号的旧会话。密码经过带随机盐的 scrypt 散列后保存。菜单显示后台地址和已配置的用户名，密码由设置者保管。

```bash
bash /opt/tiktok-knowledge/install.sh --admin-account
```

直接使用旧版安装器的用户应先运行最新版 Harvey 主脚本，再选择 **11 → 123 → 2 更新**。管理员账号设置失败时，安装器会给出重试提示，可以随后从菜单4继续设置。

自动化安装可通过 `ADMIN_SETUP_FILE` 指定权限600的 JSON 文件，内容为 `{"action":"create","username":"admin","password":"自行设置的密码"}`。安装器通过标准输入将凭据交给应用。无交互终端且未提供设置文件时，安装结束会提示运行 `--admin-account` 完成配置。该设置文件由调用者在使用后处理。

## 导出与完整备份

超级管理员在「管理后台 → 数据与备份」可以导出人员、考核记录、题库、章节与历史、素材清单、审计日志和全部数据库表。人员与考核记录提供 CSV 和 JSON，其他数据提供 JSON。

“下载完整备份”生成 `.tar.gz` 文件，包含 PostgreSQL 数据库、图片、视频和正文资源。数据库中包括人员访问令牌、权限、考试答卷、题目快照和正文历史。备份生成期间，写操作会等待数据库快照和附件归档完成。

完整备份用于恢复应用数据。目标服务器的 `.env`、域名、端口和数据库连接配置继续由该服务器的安装配置提供。迁移时先在目标服务器安装同版本或更高版本应用，再上传完整备份并运行恢复命令。恢复完成后使用备份时的管理员账号或令牌登录，也可从菜单4设置后台账号。

```bash
bash /opt/tiktok-knowledge/install.sh --restore /root/tiktok-knowledge-backup.tar.gz
```

恢复需要 Python 3。安装器先校验归档路径、数据库格式、应用版本和每个文件的 SHA256，再暂停应用与内部数据接口，保存一份 `backups/latest-pre-restore` 恢复前备份，随后恢复数据库及附件。健康检查失败时会尝试回滚到恢复前的数据。恢复前备份也包含当时的部署配置。

## 命令行维护

```bash
bash /opt/tiktok-knowledge/install.sh --update
bash /opt/tiktok-knowledge/install.sh --admin-account
bash /opt/tiktok-knowledge/install.sh --status
bash /opt/tiktok-knowledge/install.sh --logs
bash /opt/tiktok-knowledge/install.sh --set-domain https://learn.example.com
bash /opt/tiktok-knowledge/install.sh --restore /root/tiktok-knowledge-backup.tar.gz
bash /opt/tiktok-knowledge/install.sh --uninstall
```

`--set-domain` 更新应用的站点配置，域名解析和 HTTPS 反代由菜单中的域名操作完成。需要固定源代码版本时，在安装或更新命令后追加 `--ref <40位提交SHA>`。对应的 `VERSION` 必须已有同版本发布镜像。

开发者可以用 `APP_DIR`、`APP_PORT`、`SITE_URL` 和 `TIKTOK_IMAGE` 环境变量指定初始部署参数。已有安装会继续使用 `.env` 中的端口、访问地址和凭据。
